# PS BÄR Reference Images

Dieser Ordner enthält die verbindlichen Bildreferenzen für Character 01.

Bevorzugte Dateien:

- `front.jpg` — Master-Frontansicht
- `side.jpg` — Seitenansicht
- `back.jpg` — Rückenansicht
- `three_quarter.jpg` — 3/4-Ansicht

## Designregeln

Alle Ansichten müssen denselben PS BÄR zeigen: warmbraunes Plush-Fell, schwarze Cap, schwarze rechteckige Brille, schwarzer Hoodie und das PS AI MUSIC Logo. Proportionen, Gesicht, Schnauze und Kleidung richten sich nach der freigegebenen Master-Frontansicht.

## Ziel

Aus diesen Referenzen wird `../model/PS_BAER_MASTER.glb` erstellt. Das Stoffis Studio versucht immer zuerst dieses echte GLB zu laden. Nur solange es noch fehlt, wird das alte prozedurale Preview-Modell als technischer Fallback verwendet.
